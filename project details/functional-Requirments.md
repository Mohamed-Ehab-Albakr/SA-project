

Functional Requirements

1. Authentication – index.html

* FR-01: Patient Registration
    * Allow patients to create a new account by providing their personal information.
* FR-02: User Login
    * Allow users to log in using their email and password.

2. Patient Dashboard – patient-dashboard.html

* FR-03: View and Update Profile
    * Allow patients to view and update their personal information.
* FR-04: Patient Logout
    * Allow patients to securely log out of the system interface.

3. Doctors and Specialties – doctors.html

* FR-05: Browse Specialties
    * Display the available medical specialties.
* FR-06: Search and Filter Doctors
    * Allow patients to search for doctors and filter them by specialty.

4. Doctor Profile – doctor-profile.html +doctor-profile-2.html

* FR-07: View Doctor Information
    * Display the doctor’s name, specialty, profile image, and professional information.
* FR-08: View Doctor Working Hours
    * Display the doctor’s working days, hours, and available appointment slots.

5. Appointment Booking – booking.html

* FR-09: Book Appointment
    * Allow patients to select a doctor, date, and time to book an appointment.
* FR-10: Check Appointment Availability
    * Check whether the selected appointment slot is available before confirming the booking.

6. My Appointments – my-appointments.html

* FR-11: Cancel Appointment
    * Allow patients to cancel their existing appointments.
* FR-12: View Appointments
    * Display upcoming and previous appointments with their details and status.

7. Doctor Dashboard – doctor-dashboard.html

* FR-13: Doctor Dashboard Access
    * Allow doctors to log in and access their personal dashboard.
* FR-14: View Daily Schedule
    * Allow doctors to view their daily appointments and related patient information.

8. Admin Dashboard – admin-dashboard.html

* FR-15: Manage Doctors and Specialties
    * Allow administrators to add, update, and remove doctor records and manage medical specialties.
* FR-16: Manage Patients and Appointments
    * Allow administrators to view and manage patient records and appointment information.

⸻

Front-End Features

* Responsive user interface.
* User-friendly navigation.
* Form validation.
* Doctor search and filtering.
* Appointment date and time selection.
* Interactive dashboards.
* Appointment management.
* Reusable design components.
